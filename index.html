Rayih Gmail MCP

Rayih Gmail MCP is a private, single-user desktop tool that lets its owner (rayihbou@gmail.com) read his own Gmail, prepare drafts and send messages from his own Mac through a local Model Context Protocol (MCP) server. It is not offered to the public and has no hosted service.

Herramienta privada de escritorio, de un único usuario, que permite a su propietario leer su propio Gmail, preparar borradores y enviar correos desde su Mac mediante un servidor MCP local. No se ofrece al público.

Features

  • Search and read the owner's emails (gmail.readonly).
  • Create drafts and send them only after explicit confirmation in a native macOS dialog (gmail.compose).
